How to play

The idea

  1. Each run draws 7 prompts from a larger college-level pool (science, geography, languages, film, culture).
  2. Type any valid answer that fits the category.
  3. Common answers score low. Rarer correct answers score high and teach you more.
  4. Every point = +10 light-years toward rarer worlds.
  5. Perfect run = 700 → the rarest known world.
